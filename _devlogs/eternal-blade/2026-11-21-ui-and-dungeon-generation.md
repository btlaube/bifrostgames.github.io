# Post-release Update 2

***

## UI polish

*   Wielders now display archetype titles, giving each one a bit more identity at a glance.

## Seamless dungeon continuation

*   Moving between dungeons no longer triggers a scene reload, so the transition is smooth and uninterrupted.

## Enemy spawning adjustments

*   Enemies no longer spawn in the column of a vertical entrance.
*   Enemies no longer spawn in the row of a horizontal entrance.
*   This keeps entrances clear so players aren't ambushed the moment they arrive.

## Key spawn logic overhaul

*   Keys now spawn as far as possible from both the entrance and exit of their room, based on the room's current maze layout.
